# قصة المثل | أخبار المجتمع

برنامج يعرّف جمهور حسابات «أخبار المجتمع» بالقصص الموثقة ورا الأمثال العربية المعروفة. فيديوهات قصيرة بلهجة سعودية، كل حلقة تربط المثل بموقف يومي يوضح معناه ومتى ينقال.

## السكلز

| السكل | متى تُستخدم |
| --- | --- |
| [`qissat-almathal-research`](skills/qissat-almathal-research/SKILL.md) | اختيار المثل، التحقق من قصته ولفظه في المصادر، وكتابة فكرة حلقة (Pitch). |
| [`qissat-almathal-episode`](skills/qissat-almathal-episode/SKILL.md) | كتابة الحلقة كاملة: السكربت باللهجة السعودية، الستوري بورد وجدول المونتاج، الغلاف، النص على الشاشة، والكابشن. |
| [`qissat-almathal-plan`](skills/qissat-almathal-plan/SKILL.md) | خطة الموسم ومتابعة حالة الحلقات ومزامنتها مع الدرايف وأسانا. |

مراجع مساندة:
- `skills/qissat-almathal-research/references/sources.md` — مصادر الأمثال الفصيحة والشعبية والحديث والشعر.
- `skills/qissat-almathal-episode/references/delivery-template.md` — قالب تسليم الحلقة.
- `skills/qissat-almathal-episode/references/examples.md` — حلقتان منفّذتان كمرجع للشكل والنبرة.
- `examples/` — ملفات Word الأصلية للحلقات السابقة.

## سير العمل

```
فكرة → research (تحقق + Pitch) → اعتماد → episode (سكربت + جدول مونتاج) → تسجيل ومونتاج → نشر
                                      ↑
                           plan (المتابعة في أسانا والدرايف)
```

## ناقص

- **هوية «أخبار المجتمع» البصرية** (الألوان، الخط، الشعار، قوالب الغلاف): لما تتوفر، تنضاف كسكل `qissat-almathal-brand`.
